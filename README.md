# C# Exercises

A collection of beginner-to-intermediate C# practice projects organized by topic.

## What This Project Is

A hands-on C# learning repository with:

- focused topic sections
- small console-based exercises
- progression from fundamentals to OOP and testing

## Features

- Topic-based folder structure for clear learning progression
- Multiple small projects (`Oppgave*`, demos, and utilities) per section
- Coverage of core fundamentals: variables, data types, conditionals, loops, strings, and switch logic
- Introductory OOP practice (class modeling and methods)
- Basic debugging and testing exercises, including unit test examples

## Topics Covered

- Variables and basic expressions
- Data types
- Console input/output
- If/else and switch logic
- Loops and iteration
- String manipulation
- Randomized output exercises
- OOP basics and method overloading
- Debugging and unit testing fundamentals

## Notes

- Most exercises are intentionally small and focused on one concept at a time.
- Folder names like `Oppgave1`, `Oppgave2`, etc. are task-based exercises.
- This repo is structured for incremental learning and can be expanded with new sections over time.
