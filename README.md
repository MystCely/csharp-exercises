# C# Exercises  
A collection of C# exercises and small assignments

## Topics Covered

- Variables
- Data Types
- Console input and output
- Conditional logic (if/else)
- Switch statements
- Loops
- String manipulation
- Random number generation
- Object-oriented programming (basics)
- Methods and method overloading
- Debugging
- Unit testing (basic)
- Git & GitHub practice (basic exercises)

*Additional exercises and more advanced topics will be added over time.*

## Purpose  
The goal of this repository is to build a solid foundation in core programming concepts in C# through hands-on practice.
